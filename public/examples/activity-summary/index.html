Activity Summary example sources

A manual, phone-only teaching plugin using public Activities 0.4.4. These are text sources, not an installable release. Read the setup and licence notes before building.

Setup, commands and verification scope · Provider guide

To get the folder with its paths intact, copy it into a standalone working folder before following the setup commands:

git clone https://github.com/xefensor/xoce.git xoce
cp -R xoce/public/examples/activity-summary ./activity-summary
cd activity-summary

If you already have the website checkout, start at its root:

cp -R public/examples/activity-summary ../activity-summary
cd ../activity-summary

Or download the files below and keep the displayed subdirectories. The dependency is fetched separately with a verified checksum; no library archive, installed modules or PBW is included here.
