## Set up Halftone

Start with the [setup guide](/docs/pebble/halftone/). For missing readings, permissions or connection problems, see [troubleshooting](/docs/pebble/troubleshooting/).

## Report a problem

[Open an issue](https://github.com/xefensor/halftone-watchface/issues). Include the app version, your watch model and firmware, your phone and Pebble app versions, what happened, and the steps to reproduce it.

Remove private notification text, names, exact locations and installation identifiers from reports and screenshots.


## Downloads

Use the product page for the available Pebble Store and matching GitHub PBW links. A launch-preview label means that version is still being prepared. [Previous GitHub releases](https://github.com/xefensor/halftone-watchface/releases) remain separate from this preview.
