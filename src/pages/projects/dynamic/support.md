## Set up Dynamic

Start with the [setup guide](/docs/pebble/setup/#dynamic). For missing readings, permissions or connection problems, see [troubleshooting](/docs/pebble/troubleshooting/).

## Find a setting

Use **Layout & complications** for the three reading layouts, title visibility and shake switching. Use **Colours** for day/night editing and split backgrounds, **Activities** for visibility, priority and notifications, and **More & help** for display options and connection diagnostics. All categories share Save/Discard.

If a change is saved on the phone but pending on the watch, reconnect and use the watch-delivery retry. An uncertain phone save retains the draft; reload confirmed settings before assuming the change was stored.

## Report a problem

[Open an issue](https://github.com/xefensor/pebble-watchface-dynamic/issues). Include the app version, your watch model and firmware, your phone and Pebble app versions, what happened, and the steps to reproduce it.

Remove private notification text, names, exact locations and installation identifiers from reports and screenshots.


## Downloads

Use the product page for the available Pebble Store and matching GitHub PBW links. A launch-preview label means that version is still being prepared. [Previous GitHub releases](https://github.com/xefensor/pebble-watchface-dynamic/releases) remain separate from this preview.
