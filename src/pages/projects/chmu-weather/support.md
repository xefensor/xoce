## Set up ČHMÚ Weather

Start with the [setup guide](/docs/pebble/chmu-weather/). For missing readings, permissions or connection problems, see [troubleshooting](/docs/pebble/troubleshooting/).

## Report a problem

[Open an issue](https://github.com/xefensor/pebble-chmu-weather/issues). Include the plugin version, your watch model and firmware, your phone and Pebble app versions, what happened, and the steps to reproduce it.

Remove private notification text, names, exact locations and installation identifiers from reports and screenshots.

ČHMÚ Weather is an independent plugin for Czech weather locations. It runs in the official Pebble phone app. Enable Plugins / permissions preview, then choose it as your weather source. Use a saved location if you do not want to grant GPS access.

## Downloads

Use the product page for the available Pebble Store and matching GitHub PBW links. A launch-preview label means that version is still being prepared. [Previous GitHub releases](https://github.com/xefensor/pebble-chmu-weather/releases) remain separate from this preview.
