## Set up Dashboard

Start with the [setup guide](/docs/pebble/setup/#dashboard). For missing readings, permissions or connection problems, see [troubleshooting](/docs/pebble/troubleshooting/).

## Report a problem

[Open an issue](https://github.com/xefensor/pebble-app-dashboard/issues). Include the app version, your watch model and firmware, your phone and Pebble app versions, what happened, and the steps to reproduce it.

Remove private notification text, names, exact locations and installation identifiers from reports and screenshots.


## Downloads

The [product page](/projects/dashboard/) links to the current published version in Pebble Store and its matching GitHub PBW. For earlier versions, see [GitHub releases](https://github.com/xefensor/pebble-app-dashboard/releases).
